# Kata.ai

> Kata.ai is an Indonesian enterprise conversational-AI company building AI agents and chatbots for customer experience, marketing, sales, and HR. Its Kata Platform lets teams create bot projects that bundle a Bot, CMS, and a Natural Language Understanding (NLU) model, deploy them, and connect messaging channels (LINE, Telegram, WhatsApp, Facebook Messenger, Slack, Qiscus). A public REST API manages projects, bots, deployments, environments, channels, teams, and NLUs; an NL Prediction API serves trained models for entity extraction. Backed by 500 Global.

## APIs
- [Kata.ai Platform Public API](https://docs.kata.ai/kata-platform): Manage projects, bots, deployments, environments, channels, teams, and NLUs. Base URL https://api.kata.ai. Bearer-token auth; JSON only; 100 req/min.
- [Kata.ai NL Prediction API](https://docs.kata.ai/nl-studio/nl-prediction-api): POST a sentence to a deployed NLU model and receive detected entities. Base URL https://geist.kata.ai.

## Authentication
- Bearer token in the Authorization header (Authorization: Bearer <token>), or a ?token= query parameter.
- Obtain a token via POST /login (username + password), or from NL Studio > Settings for the NL Prediction API.
